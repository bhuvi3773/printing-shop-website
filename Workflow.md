# TASKS.md — Printing Shop Website

## Project Goal

Complete the initial printing shop website within the current working day using the project owner's selected template.

The website must support service discovery, product selection, pricing estimates based on verified rates, and direct customer enquiries.

## Phase 1 — Preparation

- [ ] Inspect the selected template.
- [ ] Identify its framework, dependencies, and package manager.
- [ ] Read all applicable project instructions.
- [ ] Inspect Git status and preserve existing work.
- [ ] Confirm compatibility with the proposed implementation.
- [ ] Finalize the technology stack after template inspection.
- [ ] Confirm any missing business requirements.

## Phase 2 — Template Integration

- [ ] Set up the selected template without unnecessarily restructuring it.
- [ ] Preserve its existing functionality.
- [ ] Confirm the project runs locally.
- [ ] Implement the approved requirements without independently changing the design direction.

## Phase 3 — Website Sections

- [ ] Homepage.
- [ ] Printing services catalogue.
- [ ] Product selection and customization.
- [ ] Pricing calculator.
- [ ] Our Work / Gallery.
- [ ] About the business.
- [ ] Contact and enquiry.
- [ ] Navigation and footer.

Only include business information and services confirmed by the owner.

## Phase 4 — Pricing

- [ ] Collect or confirm the actual pricing data.
- [ ] Document the pricing rules for each supported service.
- [ ] Implement calculations separately from presentation where practical.
- [ ] Validate product-specific inputs.
- [ ] Verify totals, additional charges, and rounding.
- [ ] Handle unavailable pricing with a quotation request.
- [ ] Test calculations against expected results.

Do not invent business prices.

## Phase 5 — Customer Enquiry

- [ ] Configure the confirmed WhatsApp or phone contact details.
- [ ] Include selected product specifications in enquiries.
- [ ] Include the estimated price when available.
- [ ] Validate required inputs.
- [ ] Test the contact flow.
- [ ] Confirm that no false order-confirmation message is displayed.

## Phase 6 — Content and Assets

- [ ] Add the approved business name and logo.
- [ ] Add confirmed services and descriptions.
- [ ] Add actual business contact information.
- [ ] Add approved work samples and assets.
- [ ] Remove or replace clearly identified placeholders before completion.

## Phase 7 — Testing

- [ ] Run the production build.
- [ ] Run applicable type checks and linting.
- [ ] Run relevant automated tests.
- [ ] Test the complete customer journey.
- [ ] Verify pricing calculations.
- [ ] Test contact links.
- [ ] Test representative mobile and desktop layouts.
- [ ] Check for regressions and console errors.
- [ ] Inspect the final Git diff.

## Phase 8 — Completion

- [ ] Confirm all required functionality is implemented.
- [ ] Document any missing information or incomplete features.
- [ ] Report test results accurately.
- [ ] Confirm no unauthorized files or configurations were changed.
- [ ] Leave deployment and publication untouched.

## Out of Scope

- Home delivery and delivery tracking.
- Shipping charges.
- Customer accounts and order history.
- Online payments.
- Unapproved admin dashboards.
- Unapproved backend or database infrastructure.
- Deployment, publication, and remote Git pushes.

## Completion Rule

Mark tasks complete only after the relevant work has been performed and verified. If a task is blocked by missing information, explain the dependency instead of marking it complete.
